# 相关知识面板 — 交互设计稿

> 功能：在 Viewer 中展示层3知识库的相关文档，辅助 Entry 加工时发现知识连接点。

---

## 一、用户场景

**场景**：用户在工作台打开一条 Entry（如「Obsidian 深度对话」），想知道自己的知识库里是否已有相关沉淀，以便建立连接或避免重复整理。

**当前痛点**：知识库在 GitHub 上，打开 Entry 时无法感知，只能靠记忆。

**目标体验**：打开 Entry，右侧自动出现「已有这些相关知识」，一眼看到，点击直达。

---

## 二、Viewer 整体布局变化

### 现状
```
┌──────────────────────────────────────────────────────┐
│  文件名  42KB  GitHub↗  知识库  ✏编辑  💬笔记  ✕关闭  │  ← header
├──────────────────────────────────────────────────────┤
│  🔗 Obsidian：从工具认知…  ↗   ×        + 添加链接   │  ← links-bar
├──────────────────────────────────────────────────────┤
│                                                      │
│   文档正文内容                                        │  ← body（滚动）
│                                                      │
└──────────────────────────────────────────────────────┘
```

### 新布局（body 区域横向分栏）
```
┌──────────────────────────────────────────────────────┐
│  文件名  42KB  GitHub↗  知识库  ✏编辑  💬笔记  ✕关闭  │  ← header（全宽不变）
├──────────────────────────────────────────────────────┤
│  🔗 Obsidian：从工具认知…  ↗   ×        + 添加链接   │  ← links-bar（全宽不变）
├─────────────────────────────────────┬────────────────┤
│                                     │  相关知识       │
│   文档正文内容（可滚动）              │  [搜索框]      │  ← 新增右栏
│                                     │  结果列表…      │    280px 固定宽
│                                     │                │
└─────────────────────────────────────┴────────────────┘
         ↑ flex:1，宽度自适应                ↑ 280px
```

**设计原则**：
- header / links-bar 保持全宽，视觉层级不变
- 右栏固定 280px，不挤压文档阅读区
- 右栏独立滚动，与文档滚动互不干扰

## 四、默认搜索词规则

打开 Entry 时自动填入搜索框并触发搜索，无需用户操作。

**搜索词构成**：Entry 标题 + 文件名 slug（去掉时间戳前缀）

| 示例 Entry 路径 | 自动搜索词 |
|---|---|
| `product-analysis/obsidian/202605071216-obsidian-lccm-lulu-session.md` | `Obsidian 深度对话（LCCM对话归档）obsidian-lccm-lulu-session` |
| `ai-thinking-framework/202604231045-tpm-design.md` | `TPM 设计 tpm-design` |

**用户可随时修改搜索词**，修改后 300ms 防抖触发新搜索。

## 六、结果卡片设计

```
┌──────────────────────────────────┐
│ TPM 目标画像模型                   │  ← 标题，12px，蓝色，超长省略号
│ ai-thinking-framework          ↗ │  ← repo 标签（蓝底）+ 右上角跳转图标
│ …用于描述目标用户的认知结构和       │  ← snippet，11px，灰色，2行截断
│   动机层次，由 5 个维度构成…        │    命中词黄色高亮
└──────────────────────────────────┘
```

**交互**：
- 整张卡片可点击，点击在新 Tab 打开 GitHub 文档
- Hover：`background: #eaeef2`（与现有 header-btn hover 一致）
- 无 Hover 时：`background: transparent`，`border-bottom: 1px solid #eaecef`

---

## 七、「立即同步」交互细节

| 阶段 | 按钮状态 | 背景条 |
|---|---|---|
| 默认（过期时显示） | 可点击，文字「立即同步」| 黄色 ⚠ |
| 点击后 | `disabled`，不可再触发 | 切换为蓝色 ⟳ |
| 同步完成 | 按钮消失（banner 整体隐藏）| 消失 |
| 同步失败 | 按钮恢复，文字变「重试」| 黄色，文字变「同步失败，请重试」|

## 九、不处理的场景（本版本）

- **窄屏 / 移动端**：面板暂不响应式，仅 desktop
- **语义搜索**：仅关键词匹配，不做 embedding
- **workbench 自身内容搜索**：不在范围内
- **搜索结果内预览**：点击直接跳 GitHub，不做内嵌预览

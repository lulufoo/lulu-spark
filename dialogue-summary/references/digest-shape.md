# Digest shape (dialogue-summary)

Keep a **short process overview**, not a conclusion-only abstract.

```markdown
# <Title> — 摘要

> 创建时间：YYYY年M月D日 HH:MM

## 概述

范围：全文 | Turn X～Y

骨架：
1. …
2. …（核心）
…

核心：
- <title> — 成败关键 | 基础承重 | 契约与边界
- …

关键定调（至多 3 条）：
- 〔By User〕… → 因此：…
```

Length: roughly 8–20 lines. Prefer spine fidelity over packing every detail.

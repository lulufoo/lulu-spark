> **前置依赖**：[DDM_CONCEPTS](ddm-concepts.md)
>
> **输入**：`CACHE_RAW`；从路径中解析**目录** `<topic-path>` 与**文件名** `<ts>-<slug>.md`；读取文件内容作为分析素材。
>

## [P1-1] 识别对话类型

```text
· 引导式学习 · 自由探索式 · 问题诊断式 · 方案推演式 · 查询型
```

---

## [P1-2] 归属标注

对每个归属单元标注双轴归属。

**归属单元切分依据**（任一命中即切分）：

```text
- 认知主体改变
- 引导主体改变
- 认知动作类型改变
  显式检查以下易漏边界：
  · 事实描述 vs 因果解释
  · 静态结构 vs 动态行为
  · 结论陈述 vs 约束界定
```

**跨上下文节点扫描**（归属标注后执行）：

```text
同时满足以下两项的单元，标记为「跨上下文节点」：
  · 它是某段对话的收尾（收敛、结论落地、阶段小结）
  · 它发出了新的方向信号（新问题、新类比、新约束）
处理：不随所属区段整体处理，在 [P1-3] 中独立判断
```

---

## [P1-3] 保留判断

对每个归属单元按以下顺序执行：

```text
① 强制舍弃检查
   命中则直接舍弃，不进入后续步骤：
   · 对话运转噪音（语气词、寒暄、过渡性确认）
   · 已达成共识后的重复校准
   · 不携带约束、方向界定、关键反例或切入角度的纯节奏推进内容
   · 遗留清单的中间状态记录

   「跨上下文节点」跳过此步骤，直接进入 ②

   以下不属于强制舍弃项：
   · 安全约束、设计边界、不可行条件等约束性陈述
   · 携带方向界定或切入角度的过渡内容

② 冗余判断
   此单元与已保留内容是否在说同一件事？
   · 非冗余 → 保留候选，立即执行 ③
   · 冗余 → 检查反直觉豁免：
     结论违反常见直觉预期，且此单元是必要证据 → 保留候选
     否则 → 标记为附录扫描候选

③ 双向追溯（仅对保留候选执行）

   向前——触发条件：
   · 已在保留候选中 → 通过
   · 可从已保留内容推断 → 通过
   · 两者均不满足 → 标记为「被依赖项」，直接保留

   向后——闭环落点：
   · 此单元是否闭合了前序保留事件的遗留问题？
     是 → 标记为「被依赖项」，直接保留
     否 → 通过
```

---

## [P1-4] 偏差标记

```text
分开标记两类偏差：
  · 事实性偏差：有明确对错，可被外部证据核实
    标记时同时记录触发语境（在哪一步走偏）
  · 引导质量问题：引导策略失效、方向漂移、信号判定错误，
    且对话中有用户明确指出或 AI 自我承认的记录
```

---

## [P1-5] 目标与边界扫描

```text
· 学习目标
· 主动绕过的内容
· 学习路径规划
```

---

## [P1-6] 章节规划

```text
· 按认知推进顺序组织，不按对话时间顺序
· 每章围绕 1-2 个核心疑问
· 章节顺序优先跟随用户认知推进主线，而非 AI 讲解顺序
· 不套用"是什么→怎么运作→本质是什么"等预设展开模板
```

---

## [P1-7] 诊断摘要（显式输出）

Phase 1 完成后，**必须先输出以下摘要** 到 `DIAGNOSE`（`{archive_root}/diagnose/<topic-path>/<ts>-<slug>.md`），再进入 Phase 2：

```text
## 诊断摘要

**对话类型**：[类型]

**主线概要**：一句话描述从起点疑问到收束落点的推进主线

**章节规划**：
1. [章节名] — 核心疑问：[疑问]
2. ...

**[U/U] 事件清单**（共 N 个）：
- [事件摘要] → 所属章节：[章节名]
- ...

**[U/AI] 高自主性事件**（共 N 个）：
- [事件摘要] → 所属章节：[章节名]
- ...

**反直觉结论候选**：
- [结论摘要] → 对应证据：[证据标识]
- 无则写「无」

**闭环落点标记**：
- [事件摘要] 闭合了 [前序遗留问题摘要]
- 无则写「无」

**附录候选**：
- [内容类型]：[内容摘要] → 来源章节：[章节名]
- 无则写「无」

**偏差节点**：
- 事实性偏差：[触发语境 | 偏差描述] / 无
- 引导质量问题：[描述] / 无

**目标与边界**：
- 学习目标：[内容] / 无
- 主动绕过：[内容] / 无
- 下一步方向：[内容] / 无

**入口假设**：[假设内容] → 修正为 [修正后结论] / 无
  （从第一个偏差节点的触发语境提取走偏前预设 + 对应修正结论；trace Phase 直接取此字段）

**跃迁点**：[一句话描述整体认知模型突然对齐的那一轮] / 无
  （通常是最关键的那次闭环落点，即多个前序疑问被同一机制一并解释的节点）

**全量事件序列**（按推进顺序）：
1. [[归属]] 触发：[触发条件] → 动作：[一句话] → 落点：[打开疑问 X / 终结疑问 X / 校准偏差 X]
2. ...
```

将 `DIAGNOSE` 内容写入：

```
{archive_root}/diagnose/<topic-path>/<ts>-<slug>.md
```

（目录不存在则创建）

同时更新 `{archive_root}/index.json`，将对应条目的 `"diagnose"` 设为 `true`。

完成后输出：`> ✅ Step 1 完成 · diagnose：diagnose/<topic-path>/<ts>-<slug>.md`

# lulu-spark-skills

Pack root for Lulu Spark skills. Done when the platform discovers sub-skills (`spark-task`, `spark-auto`).

## Sub-skills

| Sub-skill | Path | Role |
|-----------|------|------|
| `spark-task` | [spark-task/](spark-task/) | Workspaces, projects, documents, search, and Read Later via MCP |
| `spark-auto` | [spark-auto/](spark-auto/) | Save a knowledge unit on its own when the conversation shows a signal |

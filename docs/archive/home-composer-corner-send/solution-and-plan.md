# Home 输入框右下角发送

**状态：** 已实施
**日期：** 2026-09-23
**范围：** Home 输入框的发送按钮放到框内右下角。不改发送、锁定和占比计算。

---

## 1. 问题与目标

当前 `.home-chat-composer-dock` 是横向一排：文本框、占比、发送按钮并排（`frontend/src/home/page.tsx`）。按钮贴在文本右侧，多行时仍像框外的独立控件。

目标：发送按钮留在同一个圆角框里，固定在右下角。占比改成按钮左侧的一枚圆环，不写数字。Enter 发送、按钮禁用条件、`data-role="send"` 不变。

---

## 2. 做法

框改为纵向：上面是文本框，下面一行右对齐。底栏右侧、发送圆左边是一枚 15px 细环，放在 20px 槽里，和发送圆边缘相距 9.75px，不写文字。环从正上方顺时针。没有读数或读数为 0 时按 1% 画。悬停能看到百分比。发送圆 20px、深色，里面是 14px 线框箭头。禁用时圆和箭头都变淡，不用整颗按钮的透明度。文本高度仍按 20px 到 120px 伸缩，底栏不占这段高度。

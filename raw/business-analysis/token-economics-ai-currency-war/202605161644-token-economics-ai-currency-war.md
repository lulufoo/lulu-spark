## Token-maxxing：硅谷的新炫富方式
Time: 00:00 - 01:15

Host（陈茜）: 在硅谷，「每天烧多少 token」正在变成一种新型炫富指标。新词 **Token-maxxing** 指把 token 用量拉到极限——你每天消耗多少、能同时调度多少 agent、token 吞吐量有多高，都在变成衡量一个人「有多 AI 原生」的指标。

Host（陈茜）: 全球 AI 巨头也在激烈辩论：公司是否应不设限地鼓励员工用 token？有高管放话，年底要问年薪 50 万的工程师「今年花了多少 token」——若只花 5000 块就要「大发雷霆」；订阅 token 没用完也会焦虑。

Host（陈茜）: 辩论背后是一场围绕 token 的新军备竞赛：大厂为何疯狂卷用量？大模型如何定价？中国模型如何凭性价比杀入全球、在 OpenRouter 霸榜？「Token 套利」怎么赚差价？中国 token 出海会否成为下一个结构性机会——若上一时代出口衬衫、这一时代是电动车，下一时代会是 token 吗？

## Meta「Claudeonomics」排行榜与巨头激辩
Time: 02:00 - 05:30

Host（陈茜）: 4 月初 Meta 被曝内部 **Claudeonomics** 排行榜：汇总 8.5 万+ 员工 AI 使用数据，列出 token 消耗最高的前 250 名「超级用户」。近月排行榜总用量突破 **60 万亿 token**；按 Opus 4.6 粗算均价约每百万 token 15 美元，价值约 **9 亿美元**，榜首单人可烧掉数百万美元级别。

Host（陈茜）: Writer CEO May Habib 称这是「生死存亡级别」；她自己公司也有 token 排行榜并盯数据，认为不全力拥抱 AI 就会被淘汰。Uber 更激进：后端约 **11%** 新代码更新已由 agent 完成（三个月前还不到 1%），CTO 愿景是把软件工程转型为「agent 软件工程」。

Host（陈茜）: 反对声同样尖锐。HubSpot CEO Yamini Rangan 在 LinkedIn 称 **Outcome maxxing > Token maxxing**——比起狂烧 token，更该看产出。Jellyfish CEO Andrew Lau 直言：可以一天到晚刷 token，结果可能完全不是你想要的。

Host（陈茜）: 更多中间派仍形成共识：不充分利用 AI 的公司会被超越、变过时；哪怕排行榜不完美、部分使用最终被证明浪费，高层仍被卷着推动 AI-native 转型。

Host（陈茜）: OpenClaw 爆火后，agent 任务 token 直线上升。巨头可不顾成本烧 token，创业公司与个人开发者却焦虑：复杂任务动辄千万 token，用最贵 Claude 做小事可能十几二十美元。Uber CTO 透露 **2026 年 AI 预算开年几个月就用完**（主因 Claude Code 暴增），原话「以为够用一年的钱已经没了」。Chamath 抱怨被投 SaaS 公司启用 AI 编程工具后运营成本数月翻三倍以上，年化 AI 支出或达千万美元，「感谢 VC 为 AI 盛宴买单」。

Host（陈茜）: 对 SaaS 而言，成本结构已变：过去研发一次性、用户越多边际成本越低；现在每次操作背后都有 token 账单，用户用得越深、功能越智能，付给模型厂商的钱反而越多，难以像传统软件那样摊薄到接近零。Token 成 AI 创业最核心的「弹药」；也有风投直接给被投企业 **token 额度** 作为投资一部分——拿钱第一件事就是买 token，逻辑上 token 正在变成一种新的「货币」。

## Token 定价：三种 token 与「越贵越省」悖论
Time: 05:30 - 09:02

Host（陈茜）: Token 定价远非「单价 × 数量」。一次简单对话账单上至少三种价格：**Input**、**Cached input**（已缓存的 prompt/上下文更便宜）、**Output**。嘉宾肖志斌（研究芯片与 Token Efficiency）称对话任务上三者价格量级约 **1 : 0.1 : 6**；Output 相对 Input 往往贵得多。

Host（陈茜）: 例：GPT-5 API 约 Input 1.25、Cached 0.125、Output 10（美元/百万 token）；GPT-5.5 分长短上下文两档，长上下文价约翻倍。表面涨价数倍，却不能简单对比——**越强的模型可能总体成本越低**：弱模型反复重试、人工介入，综合成本反而更高。

Host（陈茜）: Agent 场景更复杂：非一问一答，而是 loop 里反复调用模型与工具，日志与上下文滚雪球。贵模型若一次做对、工具返回合适，可能一次完成；便宜模型可能多轮 iteration 甚至出错——故存在「越贵模型，完成任务成本可能越低」的悖论。

Host（陈茜）: 定价应综合推理成本、摊销大模型研发费用，但更关键是 **按模型质量与任务完成度**——推理能力、context window、能否快速找到正确 output；不少公司若只按推理成本定价并不可取。

## 云厂商封装与企业级溢价
Time: 09:02 - 12:04

Host（陈茜）: Azure、AWS、阿里云、火山引擎等云厂商提供模型调用，账单常含 **模型 token 费 + 云服务封装 + 企业级基础设施溢价**（区域部署、数据驻留、合规、优先推理、私有化吞吐等）。计价常据单机每秒 token 吞吐反推 GPU 成本再加 premium；也会因企业折扣或抢市场而降价。

Host（陈茜）: Post-OpenClaw 时代账单惊人，**中国开源模型** 因性价比在国际开发者社群大受欢迎：Kimi input 约不到 0.55 美元/百万 token、output 约 2.6+；MiniMax 在 OpenClaw 设置里带 **recommended** 标识。用户发现顶级能力虽略逊，但许多工作不需极高推理，**指令遵循好、速度快、便宜** 更重要；部分任务中美价差可达 **50%–70%**。当 agent 把消耗从万级推到百万级，全球开发者本能转向中国便宜模型。

## 中国模型性价比、涨价潮与黄仁勋五档定价
Time: 12:04 - 16:35

Host（陈茜）: OpenClaw 推高开源模型调用，智谱、MiniMax 等股价大涨；2026 年 3 月腾讯云、阿里云、百度智能云等 **10 天内 AI 算力涨价约 30%**。开源能力越过某门槛后，coding（token 消耗最大赛道之一）用户自然切换——智谱、Kimi 近期 coding 能力提升是诱因之一。

Host（陈茜）: SWE-Bench Verified 上 MiniMax M2.5 与 Claude Opus 4.6 约 **80.2% vs 80.8%**，体感差距极小；但 M2.5 input 约 **0.3** 美元/百万 token，Opus 约 **5** 美元——同活价格约 **1/17**。日跑千万 token 的 OpenClaw 用户，账单可从数百美元降到几十美元。

Host（陈茜）: 中国模型便宜原因：深度 **MoE**（专家更小、每次激活专家少）、生态补贴抢份额、部分云厂商（如阿里）自有成本与 margin 可打更低价。开发者 **混合用模**：复杂任务给高性能模型，简单/重复任务给便宜模型。

Host（陈茜）: 黄仁勋在 2026 GTC 提出 token **五档定价框架**：免费层（高吞吐低交互、广告变现）、中级约 3、高级 6、高速 45、超高速 **150** 美元/百万 token——token 非同质商品，价格应由交互速度与场景决定，类似电力峰谷电价。

Host（陈茜）: 暴增需求背后也有浪费：业内估计全球企业 AI 应用中近 **一半 token 可能未产生实际价值**——agent 不知「够了就停」，反复读全对话历史、重扫已处理文件，冗余上下文滚雪球。提升 **Token Efficiency** 成新赛道。

## OpenRouter：分散供给的聚合层
Time: 16:35 - 19:30

Host（陈茜）: **OpenRouter** 已成观察全球模型使用趋势的镜子，许多中国模型调用排名图出自该平台。创始人 Alex Atallah 曾任 OpenSea 联合创始人兼 CTO；2023 年起做统一入口——模型再多，开发者不想每家注册、充值、对接 API；一个接口兼容 OpenAI 格式，平台抽约 **5%** 费用。A16z 2025 年领投约 4000 万美元（估值约 5 亿），最新轮估值近 **13 亿**。

Host（陈茜）: OpenClaw 爆发让需要快速切换模型的中间层需求暴增，OpenRouter 赌的是「供给越分散，中间商越值钱」。优势：统一 API、自动 failover（延迟高或下线时切换）。局限：数据有偏——0→1 初创常用，1→10 混用，大厂多直连 Anthropic/OpenAI/Google API；更像 **创业公司与独立开发者风向标**，非全行业全景，却是中国模型出海第一波「自来水」用户群（价格敏感、愿尝鲜、迁移成本低）。

## Metronome：Token 时代的「装电表」
Time: 19:34 - 22:29

Host（陈茜）: 若 token 是 AI 时代的「电」，就需要有人装电表。**Metronome** 的客户包括 OpenAI、NVIDIA、Anthropic、Databricks 等，做 AI 计费基础设施。两位创始人出自 Dropbox，亲历 SaaS「改定价」要动一堆写死计费逻辑的痛点；AI 时代收费单位变成 token 数、API 调用、GPU 时长等细颗粒指标，每客户合同、折扣、用量阶梯各异。

Host（陈茜）: Token 公司成本比 SaaS 复杂得多（卡、电、请求峰值挤在一起，不同任务消耗完全不同）。Metronome 核心是把 **「发生了什么」与「该怎么收费」拆开**：工程上报用量事件（读/写/思考/命中缓存等），产品与销售配置价格合同，换算出账对账自动化——四层逻辑：记事件流 → 事件定价 → 订阅/API/limit 等触达层 → 销售折扣。

Host（陈茜）: 累计融资约 **1.28 亿美元**，2026 年 1 月被 **Stripe** 收购（约 100 人团队，估值追上不少模型公司）——说明 Token 经济里「怎么算钱」本身已是重大赛道。

## Token 套利与混合调度实践
Time: 22:33 - 29:20

Host（陈茜）: 开发者混用贵模型（Claude、GPT）与便宜中国模型，催生 **Token Arbitrage（Token 套利）**：用户体感差别不大时，中间商用便宜 token 换贵 token 仍收高价值价格——类似花 5000 美元请税务师把 1 万美元税优化到 2000，优化收益分成。OpenClaw 常配「便宜国产执行 + 高端 Anthropic/OpenAI 把关」；亦有 **auto tuner** 按任务细分。

Host（陈茜）: 进阶不只是批发转零售，而是 **智能路由器**：先用小模型判任务复杂度，简单走便宜模型，复杂才给 Claude/GPT，对用户黑盒、中间商优化成本。模型商自有「路由模型」；Genspark、Manus 等产品内部也按 benchmark 与经验分发任务。

Host（陈茜）: 嘉宾 **知县** 日互动数百次，给 Claude/GPT/中国模型分工：Opus 像产品经理、脑洞发散；GPT 更 nerd、像技术负责人 challenge；Codex 把关 review；执行要「有一定智能 + 快 + 便宜」——输出最贵，国产模型适合大量写代码。嘉宾 **王浩** 从工程角度：先用简单模型 detect 意图与 threshold 分流；积累数据后再 RL/fine-tune，逐步让复杂/简单场景区分更准，用户付高价值 token 却消费低价值 token。

Host（陈茜）: 短期套利有机会，但 Anthropic 等已把能力内置进 coding agent（如 Advisor 模式：贵模型判断哪些任务可用便宜模型）。跨模型调度空间远未穷尽——市场模型太多，单厂只优化自家生态；创业机会在 **任务–模型–硬件–延迟/吞吐** 更深匹配，而非仅 API 聚合与定价。通用调度系统须比 OpenRouter 更深（prompt 压缩等），否则大厂会收进自家生态。

## 中国 Token 出海：「电力出口」与供应链瓶颈
Time: 29:24 - 33:13

Host（陈茜）: 伦敦程序员用 MiniMax API 跑 OpenClaw：请求穿海底光缆到贵州数据中心，GPU 运转、电表跳，结果返回——**电未离境，价值经 API 以 token 形式跨境结算**，有人称「电力出海」。中国过去出口衬衫、家电、电动车；token 无需集装箱、无实体过海关，算力本地消耗、价值互联网交付。

Host（陈茜）: 便宜能否持续？GMI Cloud 创始人 Alex（GTC）称美国 **不缺电、缺配电能力**——高压电有，但从 330kV 降到 400V/800V 审批冗长；中美工业电价绝对差距未必想象那么大（中国约 0.4–0.6 元/度，美国约 0.8–1.2），中国优势在 **基础设施响应速度**（西部光伏 + 特高压送东部算力集群）。存储供应链也紧：DRAM 约为过去 10 倍价、CX7/电源缺货；OpenClaw、agent、多模态、coding 三重风暴下，**建够数据中心** 是物理瓶颈。另有数据跨境、延时、合规问题。

Host（陈茜）: 趋势已反映在收入：MiniMax 海外收入占比超 **七成**；Kimi K2.5 发布后数周收入超 2025 全年；智谱 API 收入爆发。Token 需求天花板尚不明显——并非人人用 OpenClaw，各垂直行业远未全面 AI 化，消耗仍增长。

## 从人类发起走向机器自动运转
Time: 33:13 - 36:16

Host（陈茜）: Token 消耗正从「人类主动发起」转向 **「机器自动运转」**：程序员手动用助手一天或烧几十万 token，agent 全天候写代码、查资料、测、部署可跳到 **千万级**；从极客扩散到普通开发者再到知识工作者，需求或呈指数增长。

Host（陈茜）: 若上一时代出口衬衫家电、这一时代电动车，下一时代可能是 **token**。对 Meta 员工是排行榜勋章，对创业公司是最大开支，对 OpenRouter 是 5% 佣金流水，对中国云厂商是把电力变美元的管道，对黄仁勋 token 将成与芯片挂钩的 **大宗商品**——历史上销售 commodity 的方式（期货、套利、批发零售、聚合、计量计费）都会在 token 上重演。

Host（陈茜）: 定价也可能进化：**Effort-based**（按复杂度）、**Task-based**（按任务完成度）等，从 token → 任务 → 业务结果复现「原油到汽油再到续航里程」的定价链。本期从 Token-maxxing、套利到 OpenRouter、Metronome，皆是古老商业逻辑的 AI 升级版——差别是速度：数月内剧烈展开，而非数十年。看完节目时，榜单、调价、新省 token 法可能又变了一轮，游戏才刚开始。

## 认知路径摘要

本次对话是一次方案推演式对话，User 主导方向推进，AI 负责精确化和修正。

对话从"三层（表示/目标/过程）是否足够"出发，AI 立刻指出缺少前置的**问题定义层**——这是第一个修正。之后 User 自发转入问题澄清的纪律讨论，通过自身案例（Mac 字体）独立识别出"中间结论当表象"这一模式，AI 将其系统化为 6 类错误。这一段落是对话中认知增量最密集的部分，中间 User 独立建构了"双向塑造"的观察和"ROI + 够用就好 + 迭代"的策略框架，AI 提供了精度补充（"够用就好"的隐含条件）。

之后 User 主动返回框架主线，推导出目标层/过程层的协作结构，以及 **Spec 密度 ∝ 层次主导性**的映射关系（User 独立推导，AI 确认）。问题定义如何体现在 Spec 里的问题由 AI 给出了反直觉答案：**Spec 的形状是问题定义压出来的，不是独立的一章**。

约束讨论阶段，User 先问边界约束分层，AI 给出性质判断框架；User 追问 CoT/证据优先的来源，AI 给出三分类；随后 User 主动反驳"过程约束应尽量少"——这是本次对话最关键的修正：AI 承认偏差并提出**补偿性 vs 替代性**区分，把一个直觉化原则变成了可操作的判断标准。

最后 User 独立引入结果层，AI 将其融入已有层次结构（形式性 vs 验证性约束）。对话以框架命名"AI + 人类协作层设计"收束。

## 认知阶段划分

### 阶段一：框架补全（问题定义层）

- **入口假设**：三层抽象（表示/目标/过程）是完整的
- **关键修正**：AI 指出表示层上游缺少问题定义层；问题陈述、边界、约束是在回答"解什么"，表示层回答的是"合法答案长什么样"
- **锚点**：问题定义里的约束（围栏）vs 领域模型里的约束（形状）——性质不同，不可合并

### 阶段二：问题澄清的纪律

- **触发**：User 自发产出字体案例，识别"中间结论当表象"
- **AI 系统化**：6 类同类错误，共同线索"离原始现象越远，越不可靠"
- **User 原创建构**（[U/U] 事件）：
  - "双向塑造"：AI 迫切给解法 + 人迫切要答案 = 正反馈，AI 协作放大偏差
  - ROI 框架 + "够用就好" + 迭代认识
- **AI 精度补充**："够用就好"的隐含条件是"能识别信号 + 愿意回头"，否则迭代变成螺旋式加深错误
- **跃迁判断**：User 在 AI 给出代价结构后，独立跳到了更高层的 ROI 框架，不是被引导到的

### 阶段三：Spec 结构与主导性

- **User 独立推导**（[U/U] 事件）：Spec 密度 ∝ 主导性 → 过程层 Spec 应尽量少
- **AI 精度修正**："留白"是结构化空间不是空白，上层欠规定下层留白变成真空，AI 用默认行为填充
- **反直觉结论**：写"过程约束尽量少"本身不是目标，而是上层写好之后的自然结果
- **问题定义在 Spec 里的位置**：不是独立章节，而是内化在表示层结构本身；Spec 的形状是问题定义压出来的

### 阶段四：约束分层与过程约束精确化

- **边界约束分层**：AI 给出性质判断框架（结构性/效果性/执行性）
- **User 反驳**（[U/U] 事件）："过程约束应尽量少"被"必须先找证据"反例击穿 → AI 承认偏差
- **核心精确化**：
  - 补偿性过程约束（填补 AI 架构局限，不可删）vs 替代性过程约束（填补上层空洞，设计缺陷信号）
  - 判断方法：删掉换成目标层等价表述，结果一样吗？一样 → 上移；不一样 → 补偿性，保留
- **"证据优先"的拆分**：防幻觉部分是 AI 局限的补偿（过程层）；信息质量要求部分性质上属于目标层

### 阶段五：结果约束与框架收束

- **User 独立引入**（[U/U] 事件）：结果层概念 + 双刃剑分析（章节结构约束 vs 来源验证约束）
- **AI 整合**：结果层按性质分配到已有层次（形式性 → 有偏离风险；验证性 → 正向）
- **框架命名**：User 提出"AI + 人类协作层设计"，AI 确认"层"承载设计决策和所有权两件事
- **框架收束**：从一句话（"表示层定义问题空间"）走到了可作为设计原则使用的完整框架

## 关键认知增量

| 概念 | 来源 | 反直觉程度 |
|---|---|---|
| 问题定义层是表示层的上游 | AI 修正 | 中 |
| 中间结论 ≠ 原始现象，离现象越远越不可靠 | User 案例 + AI 系统化 | 低 |
| 双向塑造：AI+人形成正反馈放大偏差 | User 独立建构 | 中 |
| Spec 密度 ∝ 主导性 | User 独立推导 + AI 确认 | 低 |
| 问题定义内化在表示层结构里，不是独立章节 | AI | 高 |
| 补偿性 vs 替代性过程约束 | AI（被 User 反驳后修正） | 高 |
| 验证性结果约束 vs 形式性结果约束 | User 引入 + AI 精确化 | 中 |

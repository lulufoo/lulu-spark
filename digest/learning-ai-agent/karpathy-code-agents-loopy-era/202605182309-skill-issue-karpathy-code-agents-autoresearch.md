## 概述

No Priors 对 Andrej Karpathy 的长访谈：自 2025 年 12 月起他从亲手写代码转向全天编排 coding agent 与持久化 claw，瓶颈变为 token 吞吐与并行技能；以全屋自动化「Dobby」和 AutoResearch（自主超参搜索、把人移出实验循环）为例说明「闭环时代」。他讨论模型能力的锯齿状（可验证任务强、幽默等软能力弱）、未来模型分化、不可信算力参与研究的 OpenGround 设想、就业数据与杰文斯悖论下的软件需求、前沿实验室内外角色取舍，以及开源落后约八个月的生态平衡；并延伸到机器人滞后于数字世界、MicroGPT 与「先教 agent 再教人」的教育转向。

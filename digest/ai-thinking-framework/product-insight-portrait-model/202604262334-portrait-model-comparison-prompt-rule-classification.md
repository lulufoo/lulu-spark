## 要点

1. **两个画像模型不是进化关系，是用途不同的工具**  
   旧模型（固定7元素+自评清单）解决"产品选型时的认知失误"，在成本结构和完备性检验上覆盖更完整；新模型（动态视角原型）解决"用户不清楚想要什么角度"，适用范围覆盖任意主题类型。同一产品、不同目的，两者都可能是正确选择。

2. **提示词规则有两种性质，随模型演化走向相反**  
   能力补偿型规则（弥补模型缺陷）随模型增强而收缩；意图声明型/契约型规则（明确行为契约）不因模型增强而消失。好的提示词设计，本质是尽可能只保留契约型规则，把判断留给模型。

3. **"灵敏开关"现象发生在契约类任务，而非判断类任务**  
   强模型对措辞极敏感：判断类任务（视角选择、深度校准）上规则可减少；契约类任务（停止点、格式、标注规则）上强模型会推理出"更合理变体"而偏离原文，反而需要更精确的措辞。结论：规则不是越来越少，而是两类规则分离、走向不同。

4. **提示词三层结构化消解模型适配负担**  
   将提示词分为契约层（跨模型稳定）、意图层（跨模型稳定）、判断层（随模型能力收缩）。换模型时只需调整判断层，且判断层随模型增强越来越薄——换模型成本递减，不是线性增长。长期走向：提示词越来越短（判断层收缩）且越来越精确（契约层措辞要求更高）。

## 本次对话在追什么

对话从三个日常例子出发，分析主观陈述的客观性问题，推导出 AI 接受错误前提的具体机制，并延伸到 Agent 场景下的偏差放大效应，最后确认协作层设计的防御方向：

- 转折 1：简单的逻辑谬误 AI 容易识别，但复杂度可以有效规避识别——错误前提被埋入技术细节、长对话稀释、权威外衣包裹后，AI 的前提审查会失效
- 转折 2：用户实测发现 Cursor 的 Evidence First 规则使多轮锚定测试失效——系统提示词中的元认知指令可以部分对抗锚定，但不是绝对防御
- 转折 3：对「Agent 场景本质上更严重」的结论做了自我审查——这个表述本身就犯了泛化谬误，正确表述是「在无监督、无 tracing、含不可逆操作的条件下更严重」
- 转折 4：偏差来源不止用户输入，AI 生成中间结论也会引入偏差，检索到的外部信息同样带有偏差——协作层防御需要覆盖整个链路

## 三类 AI 接受错误前提的模式

对话中确认了三个独立的偏差机制：

**模式1：多轮锚定（Premise Anchoring）**
用户在前几轮中逐步建立错误前提，AI 将已讨论的内容视为已确认的背景，不再在后续轮次重新质疑。核心问题：AI 把"已被讨论过"等同于"已被确认"。

实测案例：用高级模型构造对话脚本（Z 世代留存率高 40%），给低端模型执行，多轮锚定成功，AI 输出了"下季度 All in Z 世代"的决策报告，直到用户主动纠正数据口径才发现错误。

**模式2：批判性过度矫正（Critical Overcorrection）**
要求 AI 批判某个观点时，AI 为了表现出批判性，摆向反方向，结论同样超出了证据支撑的范围。原观点和矫正后的观点都是未加限定的泛化，只是方向相反。客观结论通常是"取决于背景/条件"，但这个结论没有前两种说法"有力"，AI 容易跳过它。

**模式3：错误前提追因（False Premise Why-Questions）**
"为什么 X？"预设了 X 为真。AI 的生成机制倾向于先接受问题结构，再填充内容，而不是先质疑前提。结果是推理链在逻辑上内部自洽，但整个链条建立在未验证的地基上。

三种模式的共同根源：AI 的生成目标是"回答问题"，而不是"先验证问题是否值得回答"。前提审查是元认知步骤，没有显式触发时经常被跳过。

## Agent 场景：偏差放大的结构

对话通过实测案例推导出 Agent 场景的风险结构，随后对"本质上更严重"的结论做了自我审查：

**有依据的部分**：Agent 会把推理结果写入文件、执行操作、生成报告，错误从"语言层"变成"具体产物"，撤销成本随不可逆操作的数量增加。

**需要修正的部分**：并非所有 Agent 任务都有这个特性。有 tracing 工具（LangSmith、Langfuse 等）的框架可以审查每步推理；有 checkpoint 的工作流中，危害程度与对话场景相近。

**修正后的准确表述**：在无人监督、无 tracing、含不可逆操作的 Agent 任务中，错误前提的危害比对话场景更大；在有人工审查节点的工作流中，危害程度与对话场景相近。

这个自我审查本身是一个元示例：Turn 9 的过度泛化，与 Turn 1 中分析的"把局部场景泛化为普遍结论"是同类问题。

## 偏差来源的完整链路

对话最终确认：偏差不止来自用户输入，整个协作链路上都在产生偏差：

```
用户输入 → [偏差①：主观认知偏差]
    ↓
AI 生成中间结论 → [偏差②：训练数据分布偏差、生成倾向偏差、上下文滚雪球]
    ↓
检索外部信息 → [偏差③：搜索排名偏差、RAG 文档质量偏差]
    ↓
AI 整合输出 → 叠加三类偏差的最终结果
```

**AI 对检索结果的信任度高于用户输入**：检索到的内容有"外部来源"的外衣，反而比用户输入更容易被直接接受而不审查。

**协作层防御的正确范围**：不能只防用户输入偏差（入口防御），需要在整个链路上设置审查节点。

## 对 AI 偏差识别能力的准确定位

「AI 无法识别主观认知偏差」——这是过强的表述。

准确表述：AI 在没有显式触发前提审查时，倾向于接受输入的认知框架，而不是主动检测其中的偏差。区别在于：不是"无法"，而是"默认不做"。在偏差足够显著或有明确指令（如 Evidence First 规则）时，AI 是可以识别的。

**真正的风险不在 AI 的能力上限，而在使用方式的默认设定上。**

---

## 实测发现：元认知指令是有效防御

Cursor 的 Evidence First 规则（"先验证前提，再作结论"）使多轮锚定测试失效。机制是：系统提示词在每轮对话开始时注入，相当于给模型加了持续激活的前提审查指令，推动模型在生成前进入元认知模式。

防御边界：对简单锚定有效；对深度嵌入技术细节的前提、权威身份断言、极长上下文中的早期前提，仍可能失效。

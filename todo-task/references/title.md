# Todo title

User-given title: use as given.

Otherwise:

```text
{what this work is}（{WorkType}）
```

`WorkType` is required and must be one of:

```text
效果分析 | 问题描述与分析 | 选型分析 | 对比分析 | 方案 |
缺陷修复 | 流程优化 | 执行待办 | 待优化计划
```

Length: live MCP schema. If too long, shorten the `{what}` part; do not drop `WorkType`.

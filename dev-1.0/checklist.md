# 功能回归验证清单 v1.0

> 每个 Phase 结束后，在 commit 之前按此清单逐条验证。
> 全部通过才能 git commit 并进入下一 Phase。
> 验证时打开 DevTools Console，确认无红色报错。

---

## 验证前置条件

```bash
python3 server.py   # 确认服务器已启动
open http://localhost:8000
```

---

## 基础功能（每 Phase 必须全部通过）

| # | 功能区 | 验证步骤 | 预期结果 |
|---|---|---|---|
| 1 | 启动 | 打开页面，查看 DevTools Console | 无红色报错，页面正常加载 |
| 2 | 侧边栏 | 查看左侧日期列表 | 日期按降序排列，count 数字与当日文档数一致 |

| 4 | Session 恢复 | 选中某个日期后刷新页面（Cmd+R） | 恢复上次选中的日期，滚动位置基本恢复 |
